# Modelo 1 - Guia de Estilo Douglas Amorim

**Template demonstrativo aplicando as diretrizes visuais extraídas da página de referência**

## Elementos do Guia

### Tipografia
Playfair Display para títulos (700) e Raleway para textos (400). Hierarquia clara com tamanhos específicos para cada elemento.

### Layout
Design responsivo com containers centralizados, grid flexível e espaçamentos consistentes entre elementos.

### Componentes
Botões com bordas arredondadas, cards com sombras sutis e navegação horizontal no header.
